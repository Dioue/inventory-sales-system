# Demo Repo 
*Inventory and Sales Management System wtih Trial Demand Forecasting for short term forecasting using TSB Model.*

![Demo Img](https://github.com/Dioue/JJAS-ISS/blob/main/jjas/media/products/images/Demonstration%20System.png)

DEMO: https://isms.dioue.dev/

### requirements
> cd jjas && pip install -r requirements.txt
> npm install -g tailwindcss
> npm install flowbite
> npm install simple-datatables --save
> npm install apexcharts --save

### To start tailwind

> npx tailwindcss -i ./static/css/tailwind.css -o ./static/css/output.css --watch

### To start backend django
> python manage.py runserver
